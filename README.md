# Valverde’s Minimarket

React + Vite storefront and Express/Sequelize API. Existing PHP/HTML files remain unchanged; catalog images and the legacy stylesheet are available under `client/public/`.

## Local development

1. Install Node.js 20.18+ and start a local MySQL server.
2. Create the database: `CREATE DATABASE valverdes_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
3. Copy `.env.example` to `.env` and set `JWT_SECRET`. The default MySQL connection uses `localhost`, user `root`, an empty password, and database `valverdes_db`.
4. Run `npm install`, `npm run db:migrate`, and `npm run db:seed`.
5. Run `npm run dev`. Vite serves `http://localhost:5173` and proxies `/api` requests to Express on port `3001`.

The seed parser reads the existing `categoria_*.html` pages and `data/productos.json`, deduplicates entries, and seeds 119 catalog products plus default offers and about-page copy. The development seed creates `admin` / `admin123` (`admin@valverdes.local`). This default must not be used in production; Render requires an `ADMIN_PASSWORD` secret.

## Production deployment

- **Vercel:** deploy the repository root using `vercel.json`; set `VITE_API_URL` to the public Render API origin.
- **Render:** create the web service from `render.yaml`, set `ADMIN_PASSWORD`, a strong `JWT_SECRET` (generated by the blueprint), and `CLIENT_ORIGIN` to the Vercel site URL. Render provisions PostgreSQL and supplies `DATABASE_URL`; the start command runs schema migration and seeding before starting Express.
- Optional combined/static serving: set `SERVE_CLIENT=true` after building the client.

## API

`GET /api/health`, `/api/products`, `/api/products/:id`, `/api/offers`, `/api/about`; customer auth at `/api/auth/register`, `/api/auth/login`, `/api/auth/logout`, and `/api/auth/me`; admin-only product/offer/content management, `/api/users`, `/api/orders`, `/api/orders/:id/status`, `/api/dashboard`, and `/api/catalog/import`. Orders can be submitted by guests or authenticated customers. Admin endpoints require a Bearer JWT.

`npm test` runs API health and catalog-import smoke tests; `npm run build` builds the Vite frontend.
